# natural-rewriting-prompt

## English

A prompt for editing texts across subjects and genres, available in versions for [Russian](prompt.ru.md) and [English](prompt.en.md). It helps remove formulaic phrasing and mechanical rhythm while preserving meaning, facts, terminology, and the author's voice.

Give the prompt and source text to an AI agent system running in a harness with file access and tools for editing and checking text. Optionally specify the desired tone and length or provide a sample of the desired style.

## Русский

Промпт для редактирования текстов разных жанров и тематик. Доступен в двух версиях: [для русского языка](prompt.ru.md) и [для английского языка](prompt.en.md). Помогает убрать шаблонные обороты и механический ритм, сохранив смысл, факты, терминологию и авторский голос.

Передайте промпт вместе с исходным текстом агентной ИИ-системе, работающей в среде выполнения (harness) с доступом к файлам и инструментам редактирования и проверки текста. При необходимости добавьте требования к тону и объёму или образец желаемого стиля.
